# Pactto

Proposta comercial no celular, com PDF para o cliente.

Documentação formal: [docs/documentação detalhada.md](docs/documentação%20detalhada.md).

## Rodar

Requer Flutter com Dart 3.13 ou superior. Na raiz, `flutter pub get`.

```bash
cd apps/pactto
flutter run
```
